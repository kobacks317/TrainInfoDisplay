# ディレクトリ構成

本アプリは「メインウィンドウ（M系）」と「表示ウィンドウ（D系）」の2種類のブラウザウィンドウで構成される
（詳細は [docs/01_requirements.md](../docs/01_requirements.md) §1.2、[docs/02_screen_design.md](../docs/02_screen_design.md) §1 を参照）。
それぞれの責務を分離するため、`src/` 配下は以下の3つに分割する。

| ディレクトリ | 対応ウィンドウ | 責務 |
| --- | --- | --- |
| [`main/`](./main) | メインウィンドウ（M系） | 設定・操作用SPA。マスタ管理、画面デザイン定義、列車選択、状態設定、表示ウィンドウの起動など |
| [`display/`](./display) | 表示ウィンドウ（D系） | 案内表示用ポップアップ。状態のプッシュ受信、スライドショー再生、レイアウト描画など |
| [`shared/`](./shared) | 共通 | 両ウィンドウで共有するデータモデル、ウィンドウ間通信、i18n、モックデータなど |

## ビルド方針

現時点ではビルドツール（Vite等）は導入せず、ブラウザネイティブの ES Modules のみで構成する。
`index.html` / `display.html` から `<script type="module">` で各エントリポイントを直接読み込む。

理由:

- 現在の画面数・依存パッケージ数の規模ではバンドラー導入（コード分割、HMR等）の恩恵より設定コストの方が大きい
- `CLAUDE.md` に記載の使用技術（JavaScript, HTML, CSS, JSON）とも合致する
- 将来、画面数や依存パッケージが増えた場合は改めて導入を検討する

## エントリポイント

| HTML | JS | 用途 |
| --- | --- | --- |
| `index.html` | `src/main/index.js` | メインウィンドウ（M系） |
| `display.html` | `src/display/index.js` | 表示ウィンドウ（D系）。メインウィンドウから `window.open` でポップアップとして起動する想定 |
