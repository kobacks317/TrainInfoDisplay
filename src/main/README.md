# src/main（メインウィンドウ / M系）

設定・操作用のSPA。画面定義は [docs/02_screen_design.md](../../docs/02_screen_design.md) の M系画面（M-01〜M-31）を参照。

## 責務

- ログイン・認証
- 運行（列車）の選択、現在地・号車・列車状態・遅延の設定
- テンプレート／レイアウト／スライドショー／シンボルデザイン／多言語テキストなどの管理画面
- 表示ウィンドウ（D系）の起動・一覧管理
- サーバーへの状態更新、および `src/shared` の通信層を介した表示ウィンドウへのプッシュ配信

## 現状

プレースホルダーの `index.js` のみ。画面の実装は今後のIssueで追加する。
