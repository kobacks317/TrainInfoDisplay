# src/display（表示ウィンドウ / D系）

案内表示用のポップアップウィンドウ。画面定義は [docs/02_screen_design.md](../../docs/02_screen_design.md) の D系画面（D-01, D-02）を参照。

## 責務

- メインウィンドウからの状態プッシュ（`BroadcastChannel`）の購読
- スライドショーの再生（対象の列車状態でフィルタしつつレイアウトを巡回表示）
- 各コンポーネントのレンダリング
- 接続断時の縮退表示（D-02）

## 現状

プレースホルダーの `index.js` のみ。画面の実装は今後のIssueで追加する。
